# AI기반 민군경 융복합 해양데이터 분석활용 기술 개발 (1단계 2년차)

**기관** 해양수산과학기술진흥원 · **기간** 2024.08 ~ 2025.12 · **기여도** 50%

## 개요

해수부·해군·해경 간 보안 해양데이터 공유·활용을 지원하는 보안 플랫폼 구축 및 AI 기반 분석·활용 기술 개발(R&D) 사업입니다.

## 담당 역할

- UI 설계, 데이터베이스 설계, 시퀀스 설계, 인터페이스/컴포넌트 설계
- 시나리오 모델 결과 서빙 분석 및 테스트
- 웹 서비스 개발(Frontend, Backend) 및 테스트

## 개발 내용

블록체인 기반 보안 플랫폼과 연계된 해양 데이터를 API Gateway로 수집하고, 민·군·경이 활용 가능한 지능형 해양 데이터 AI 분석 플랫폼을 개발했습니다. eGovFramework 4.3 기반 백엔드와 FastAPI 기반 AI 서빙 레이어를 구축해 타사 모델의 분석 결과를 실시간으로 웹 서비스에 연동 테스트했습니다. 수심·지형 변화 예측, 사고다발 분석 등 8종의 AI 분석 시나리오를 GIS 지도 인터페이스에 매핑했으며, 해양 사고 위험 지역 실시간 알람 시스템과 관리자 대시보드를 구축했습니다. Open API 신청/승인 워크플로우를 구현하고, AG-Grid를 도입해 대규모 해양 메타데이터 조회 성능을 최적화했습니다.

## 기술 스택

- Frontend: JavaScript, jQuery, AG-Grid
- Backend: Java 17, eGovFramework 4.2.0 (Spring Framework), FastAPI (Python)
- DB / Tools: PostgreSQL, eXERD, Eclipse, VSCode, Maven, Figma, draw.io, Gitea

## 트러블슈팅

**문제**: 서로 다른 인터페이스를 가진 8종의 AI 모델 분석 결과를 실시간 연동해야 했고, 결과 데이터 형식(파일, 공간레이어, 수치)이 제각각이라 저장 구조 설계가 까다로웠습니다. Spring과 Python으로 작성된 AI 모델 간 통신 및 다중 요청 분기 처리 방안도 부재했습니다.

**해결**: 웹 서비스가 모델에 제공하는 투입 변수와 결과 데이터 형식을 분석해 공통 속성을 추출하고, 모델별 고유 특성을 수용하면서 중복을 배제한 정규화된 통합 데이터 모델링을 수행했습니다. Spring과 AI 모델 사이 중계로 FastAPI를 도입해 비동기 기반 실시간 연동 환경을 구축했습니다.

## 아쉬운 점

실제 비즈니스 로직을 처음부터 끝까지 설계하며 유지보수의 중요성을 체감했고, 협업을 위한 커밋 컨벤션과 코드 표준화 기준을 사수와의 소통을 통해 점차 정립했습니다.
