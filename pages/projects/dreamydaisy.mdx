# DreamyDaisy

**형태** 토이 프로젝트 · **기간** 2024.04 ~ 2024.06 · **기여도** 100%

## 개요

키링 판매 웹 쇼핑몰 프로젝트로, 회원가입·로그인·장바구니 기능을 갖춘 커머스 서비스를 처음부터 구현했습니다.

## 담당 역할

- 프로젝트 기획, 웹 서비스 구현 전반

## 개발 내용

- 회원정보 DB 관리, 메인/로그인/회원가입/장바구니 페이지 구현
- Spring Security `BCryptPasswordEncoder`로 비밀번호 암호화
- DTO 도입으로 클라이언트-서버 간 데이터 전송 시 도메인 객체와 분리

## 기술 스택

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Java, Spring Boot, MySQL, Maven, MyBatis, Spring Security

## 트러블슈팅

**문제**: 아이디·비밀번호가 평문으로 저장되고, 도메인 객체가 DB와 직접 연결되어 있어 보안에 취약했습니다.

**해결**: `BCryptPasswordEncoder`로 비밀번호를 해시화하고, DTO를 도입해 도메인 객체와 전송 데이터를 분리했습니다.

## 아쉬운 점

Spring Boot를 처음 사용하며 간단한 CRUD 구현에도 많은 시간이 소요되어, 기능 구현에 비해 화면 디자인에는 상대적으로 시간을 쏟지 못했습니다.
