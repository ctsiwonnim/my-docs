# New Branch (뉴브랜치)

**형태** 팀 프로젝트 · **담당 파트** 백엔드 + 프론트엔드

## 개요

학습자가 스스로 학습 목표를 설정하고, 자료를 업로드·정리하며, 탐구 주제 투표·마인드맵·기록·성찰까지 학습의 전 과정을 하나의 흐름으로 연결하는 교육용 AI 학습 플랫폼입니다. 기획·백엔드 개발로 시작해 베타 → 정식 출시를 목표로 프론트엔드·디자이너와 함께 기능을 안정화하고 있습니다.

## 담당 역할

**Backend**
- 로그인/로그아웃 기능 및 사용자 조회 API 구현
- 회원가입 인증코드 전송 로직 구현
- 나만의 학습(MyLearning) 도메인 구현 및 리팩토링
- 단권화(Consolidation) CRUD 구현
- MyLearning IDOR, OAuth2 보안 취약점, JWT 검증 등 보안 이슈 수정
- 테스트 코드 작성, EC2 배포 설정 및 main 배포 작업

**Frontend**
- 회원가입 / 로그인·로그아웃 화면 구현
- 단권화(Consolidation) 페이지 화면 구현
- 인증 쿠키 처리 로직 정리 및 리팩토링

## 기술 스택

- Backend: Java 17, Spring Boot 3.2.4, Gradle 8.5, PostgreSQL 15, Springdoc OpenAPI, JWT/OAuth2, Docker
- Frontend: Next.js (App Router), React, vanilla-extract (CSS-in-TS), FSD 유사 구조 (entities/features/shared/views/widgets)
- Infra: GitHub Actions(CI/CD), Docker Hub, EC2, Vercel(문서 배포)

## 아키텍처 특징

DDD(Domain-Driven Design) 패턴 기반으로 attachment, code, consolidation, goal, mylearning, user 등 도메인별 패키지를 분리했습니다. 프론트엔드는 FSD(Feature-Sliced Design)와 유사한 계층 구조에 Next.js App Router를 결합했습니다.

## 트러블슈팅

**IDOR 취약점**: 나만의 학습(MyLearning) 리소스 접근 시 소유자 검증이 누락되어 다른 사용자의 데이터에 접근 가능한 문제를 발견해 수정했습니다.

**인증 보안**: OAuth2 로그인 흐름과 JWT 검증 로직의 보안 취약점을 점검·보완하고, EC2 배포 설정까지 함께 진행했습니다.

## 프로젝트 현황

Spring Boot 기반 프로젝트 구조(DDD 패턴), Docker Compose 개발 환경, GitHub Actions CI/CD 파이프라인 구축을 완료하고 도메인별 기능 구현 단계를 진행 중입니다.
