# 서울시 1인가구 범죄예측 분석지도

**역할** 팀장 · 프로젝트 기획, 알고리즘 설계·구현, 발표 · **기간** 2023.07 ~ 2023.11

## 개요

서울시 1인가구 밀집 지역의 범죄현황·거주인구·시설특성 데이터를 수집해 **XGBoost**로 범죄위험도 예측 모델을 만들고, **SHAP**으로 주요 증가 요인을 분석해 지도로 시각화했습니다. 도출한 범죄위험도를 QGIS 격자 속성정보에 반영하고, 서울시가 구축한 3차원 가상현실 지도 s-map에 매핑했습니다.

## 개발 내용

- 250×250m 단위 격자 공간 데이터로 범죄 데이터 가공
- Geopandas/Shapely 기반 공간 데이터 전처리 및 변수 변환
- XGBoost 모델로 범죄위험도 예측, SHAP으로 주요 요인 분석
- Folium/QGIS로 범죄 예측 결과 지도 시각화

## 기술 스택

- Python (Scikit-Learn, Pandas, XGBoost, SHAP, Geopandas, Folium, JSON)
- QGIS, VSCode

## 트러블슈팅

**문제**: 좌표 기반 독립·종속 변수를 격자 단위로 변환하는 과정에서 데이터 양이 방대하고 전처리가 복잡했습니다.

**해결**: Geopandas와 Shapely로 데이터를 격자 단위로 정리하고 공간적 특성을 반영하도록 변수를 변환했으며, 팀원별로 담당 영역을 나누어 처리했습니다.
