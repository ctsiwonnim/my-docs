# 감성 분석을 이용한 서울시 민원 빅데이터의 공간적 시각화 방안

**기관** 대한토목학회/한국측량학회 공동 학부생 연구논문 발표회 (장려상) · **기간** 2022.07 ~ 2022.11 · **기여도** 30%

## 개요

민원 접수량만으로 사안의 심각성을 평가하던 기존 방식에서 벗어나, 헤도노미터 기반의 부정 감성 점수(BlueScore)를 도입해 민원의 고충 심각성과 처리 시급성을 직관적으로 파악할 수 있도록 시각화한 프로젝트입니다.

## 담당 역할

- 프로젝트 기획
- 민원 데이터 크롤링, 전처리, 민원 지도 가시화

## 개발 내용

서울시 민원 데이터를 크롤링해 공간 데이터를 전처리하고, 헤도노미터 점수표를 활용한 감성분석으로 민원 키워드 순위를 도출했습니다. Mapbox 라이브러리로 민원 정보를 지도에 가시화했습니다.

## 기술 스택

- Python (Geopandas, JSON, Mapbox, Folium)
- VSCode
