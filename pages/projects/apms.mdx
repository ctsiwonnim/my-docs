# 26년 사내시스템 구축 운영(APMS) — 사업비 정산 시스템

**기관** (주)올포랜드 · **기간** 2026.01 ~ 현재 · **기여도** 30%

## 개요

엑셀로 수기 관리되던 회사 프로젝트별 사업비 정산 프로세스를 웹 서비스로 전환하는 사내 인트라넷 시스템 개발 프로젝트입니다.

## 담당 역할

- 현업 요구사항 분석 및 정의
- 화면 UI 설계, 데이터베이스 설계, 시퀀스 설계
- 웹 서비스 개발 (Frontend, Backend)

## 개발 내용

전자정부프레임워크 3.10 기반으로 통합 정산 시스템을 구축했습니다. 사업관리 담당자 인터뷰와 기존 회계 시스템 분석을 통해 상세정산·인건비·차량유지비 등 6종의 정산 항목 요구사항을 도출하고, 엑셀 기반의 복잡한 정산 수식과 산출 로직을 Java 백엔드로 구현해 데이터 무결성을 확보했습니다. 경영본부 제출까지의 워크플로우를 디지털화하고, 전사 프로젝트 비용 관리에 최적화된 DB 모델링을 진행했습니다.

## 기술 스택

- Frontend: JavaScript
- Backend: Java 17, eGovFramework 3.10 (Spring Framework)
- DB / Tools: PostgreSQL, eXERD, Eclipse, Maven, draw.io, SVN

## 트러블슈팅

**문제**: 공식 요구사항 정의서가 부재한 상태에서 개발이 시작되어, 사업비 정산이라는 전문 회계 도메인 지식이 부족해 초기 설계에 어려움을 겪었습니다. 프로젝트마다 다른 정산 예외 케이스를 표준화하는 작업도 필요했습니다.

**해결**: 사업관리 담당자들을 대상으로 수시 인터뷰를 진행해 실제 정산 업무 흐름과 예외 상황을 조사하고, 이를 바탕으로 프로젝트별 정산 규칙을 로직화하여 시스템 설계에 반영했습니다.

## 아쉬운 점

별도 퍼블리싱 지원 없이 기존 사내 인트라넷 UI를 재활용해야 해서, 최신 웹 트렌드나 고도화된 퍼블리싱 디자인을 적용하지 못했습니다.
